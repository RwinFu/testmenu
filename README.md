# کافه رُست — منوی دیجیتال

یک منوی فارسی و واکنش‌گرا برای موبایل، همراه با تصاویر اختصاصی، پنل مدیریت سبک و QR قابل چاپ. سایت بدون فریم‌ورک و بدون build step ساخته شده است.

## انتشار روی GitHub Pages

یک GitHub Actions workflow در `.github/workflows/pages.yml` قرار دارد. پس از ادغام تغییرات در شاخه‌ی `main`، از تنظیمات مخزن به **Settings → Pages** بروید و در صورت درخواست، Source را روی **GitHub Actions** قرار دهید. پس از اجرای موفق workflow، سایت در آدرس زیر در دسترس خواهد بود:

**https://rwinfu.github.io/testmenu/**

فایل `qr-menu.svg` و صفحه‌ی `qr.html` از همین آدرس استفاده می‌کنند؛ پس از فعال شدن Pages می‌توان QR را چاپ و اسکن کرد.

## مدیریت منو

- صفحه‌ی عمومی: `index.html`
- پنل مدیریت: `admin.html`
- صفحه‌ی چاپ/دریافت QR: `qr.html`
- داده‌های پیش‌فرض: `menu-data.json`

پنل مدیریت بدون سرویس یا وابستگی سنگین اجرا می‌شود. تغییرات ابتدا فقط در `localStorage` همان مرورگر نگه‌داری می‌شوند؛ بنابراین این پنل احراز هویت یا ذخیره‌سازی ابری ندارد و به‌تنهایی نمی‌تواند منوی بازدیدکنندگان دیگر را تغییر دهد. برای انتشار تغییرات، در پنل **خروجی گرفتن** را بزنید و فایل دانلودشده‌ی `menu-data.json` را در GitHub جایگزین فایل هم‌نام کنید و تغییر را commit کنید. تصاویر قابل انتخاب، در پوشه‌ی `assets/` هستند.

## اجرای محلی

به‌دلیل محدودیت `fetch` در باز کردن مستقیم فایل‌ها، سایت را با یک وب‌سرور ساده اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000/` را باز کنید.
